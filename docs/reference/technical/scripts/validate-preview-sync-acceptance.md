# validate-preview-sync-acceptance

Implements exact timing validation.
## `assertSyncSuppressionMargin`
Requires the stage margin.
## `validateNormalSyncObservation`
Requires visibility within 120 seconds.
## `firstEligibleRepairTick`
Rounds to the eligible quarter-hour.
## `validateRepairObservation`
Requires reservation and next-tick visibility.
## `instant`
Returns epoch milliseconds.
## `canonicalInstant`
Requires canonical UTC.
## `fail`
Throws the constant error.
