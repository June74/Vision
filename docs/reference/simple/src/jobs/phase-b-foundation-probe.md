# `src/jobs/phase-b-foundation-probe.ts`

Turns aggregate preview measurements into one exact privacy-safe evidence
record.

## `createPhaseBFoundationProbeEvidence`

Admits safe counts and selects the first deterministic failure category.

## `runPhaseBFoundationProbe`

Runs only for the exact preview environment and maps failures to closed
evidence.

## `emitPhaseBFoundationProbeEvidence`

Writes only the fixed action and closed evidence.

## `semanticCategory`

Chooses the first failed contract check in the approved order.

## `unavailableEvidence`

Creates the fixed zeroed shape for unavailable sources.

## `isExactPreviewEnvironment`

Accepts only the one-field preview environment object.

## `isValidDate`

Accepts only a real finite observation time.
