# `src/jobs/temporary-preview-fault.ts`

Runs one temporary preview test and writes one short safe result for the
observer. It has no route and does not reveal provider details.

## `createTemporaryPreviewFaultEvidence`

Builds the exact four-part record for one scenario. Five display scenarios
succeed with `none`; the R2 upload check records its fixed write failure.

## `runTemporaryPreviewFault`

Checks the generated preview binding before it can call a dependency. The R2
case uses a writer that fails before a real storage upload can begin.

## `putIfAbsent`

The temporary R2 writer always fails before forwarding a storage write.
