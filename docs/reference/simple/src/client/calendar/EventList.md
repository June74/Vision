# `src/client/calendar/EventList.tsx`

## `EventList`

Shows synchronized events in chronological order with local title, time, timezone, status, and category notes. It explains when no events have synchronized.

## `formatDate`

Formats the event day in the event's own timezone.

## `formatTime`

Formats the start or end time in the event's own timezone.

## `formatEventStatus`

Turns the stored event status into readable text.
