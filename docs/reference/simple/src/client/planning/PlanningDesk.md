# `src/client/planning/PlanningDesk.tsx`

Shows a template briefing, time suggestions, and local follow-ups. The surface
labels every calendar result approval-required and offers no confirm button.

## `PlanningDesk`

Renders the authenticated planning desk.

## `submitProposal`

Requests a bounded deterministic time suggestion.

## `submitFollowUp`

Saves a local follow-up.

## `changeFollowUp`

Applies a server-confirmed local transition.

## `ProposalCard`

Displays alternatives and the no-confirmation boundary.
